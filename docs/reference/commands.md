# Commands

None has a default hotkey; assign them under Settings → Hotkeys.

| Command | Does |
|---|---|
| **Look up at cursor** | Runs immediately on the typed `/thesaurus::` command, else on the selection, else on the word under the cursor. The pick replaces that word. |
| **Open thesaurus history** | Opens the history pane on the right. Also the book icon in the ribbon. |
| **Clear cached answers** | Forgets every cached lookup (`cache.json` in the plugin folder). |

Inside the box: `↑` `↓` choose, `Enter` insert, `Esc` close. See [The box](/guide/the-box).
